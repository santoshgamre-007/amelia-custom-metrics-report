Where do the conversations come from?

The app reads each conversation and its transcript, maps everything to the customer’s custom-metrics dictionary, and builds the dashboard and the PowerPoint.

A · From Amelia

Sign in to the console in your browser, then copy amelia_s from that same host (F12 → Application → Cookies).

B · Or use an exported file

In the Amelia console: Conversations → Export (include transcripts). Any .csv, .zip or .gz export works.
